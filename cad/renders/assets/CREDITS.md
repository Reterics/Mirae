# Render assets

Every asset here comes from Poly Haven and is CC0 (public domain): no attribution is required, though it's appreciated.

The files themselves are git-ignored. Re-download them with:

```
python cad/blender/fetch_assets.py
```

| Asset | Used for | Source |
|---|---|---|
| Photo Studio Loft Hall (4k HDRI) | Interior lighting and reflections | https://polyhaven.com/a/photo_studio_loft_hall |
| Laminate Floor 02 (2k textures) | Wood floor | https://polyhaven.com/a/laminate_floor_02 |
| Modern Arm Chair 01 | Furniture | https://polyhaven.com/a/modern_arm_chair_01 |
| Mid Century Lounge Chair | Furniture | https://polyhaven.com/a/mid_century_lounge_chair |
| Modern Coffee Table 01 | Furniture, and a scale cue next to the robot | https://polyhaven.com/a/modern_coffee_table_01 |
| Book Encyclopedia Set 01 | Props on the table | https://polyhaven.com/a/book_encyclopedia_set_01 |
| Potted Plant 02 | Plant in the corner | https://polyhaven.com/a/potted_plant_02 |

`cad/blender/render_lifestyle.py` builds the walls, skirting boards and window light itself; they aren't downloaded assets.
